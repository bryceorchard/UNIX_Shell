◆ execute()

int execute ( struct cmdline * l)

Executes a command pipeline.

Every command is started before any is waited on: waiting for each in turn deadlocks as soon as a command writes more than the pipe buffer holds, since its reader has not been started yet. So only the last command is waited on as it is launched; the earlier ones are waited on once it has finished. All descriptors the shell opens are close-on-exec, so a child keeps only its own stdin/stdout; in particular a writer keeps no copy of its pipe's read end, so it gets SIGPIPE when the reader exits early (e.g. yes | head -n 1).

A background command line is recorded as a single job, whatever the number of commands in its pipeline.

Parameters
lA pointer to a cmdline structure containing the parsed command.
Returns
0 on success, or a non-zero value on error.

int execute_command ( char * cmd,
char ** args,
int in,
int out,
int bg )

Executes a single, simple command in another process: handles the jobs builtin, forks, wires up stdin/stdout, execs the program, and waits for it unless it runs in the background. Background children are recorded in the job table by execute(), once per pipeline.

Parameters
cmdProgram to run (looked up in PATH).
argsNULL-terminated argument vector, args[0] == cmd.
inFile descriptor the command reads from (STDIN_FILENO if none).
outFile descriptor the command writes to (STDOUT_FILENO if none).
bgNon-zero to return without waiting for the command. execute() passes this for background commands, and for every command of a pipeline but the last, which it waits for itself once the whole pipeline is running.
Returns
The child's pid, 0 if the command was a builtin run in the shell itself, or -1 if fork failed.
