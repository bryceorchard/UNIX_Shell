◆ add_job()

int add_job ( const pid_t * pids,
int count,
const char * cmd )

Records a background job (a command or a whole pipeline) in the first free slot. Call with SIGCHLD blocked, from before the first process is forked, so the handler cannot see a process of the job finish before the job is recorded.

Parameters
pidsProcess ids of the job's processes; entries <= 0 (commands that were not started) are skipped.
countNumber of entries in pids.
cmdCommand line shown by jobs (truncated to JOB_CMD_MAX - 1 chars).
Returns
0 on success (or if no process was started, so there is nothing to record), -1 if the table is full or the job has more than JOB_PIDS_MAX processes.

◆ remove_job()

int remove_job ( pid_t pid)

Records that a background process finished. When it was the last running process of its job, prints the job's computation time and frees the slot. Async-signal-safe (no malloc/free/stdio), so the SIGCHLD handler calls it.

Parameters
pidProcess id that finished.
Returns
0 on success, -1 if pid was not tracked.

◆ set_waiting_prompt()

void set_waiting_prompt ( const char * line)

Tells the completion reporter whether the shell is waiting at its prompt. If it is, a completion message erases the prompt line and redraws the prompt below the message. Call with SIGCHLD blocked.

Parameters
lineThe prompt exactly as printed (colour codes included), or NULL once the shell is no longer waiting at the prompt.
