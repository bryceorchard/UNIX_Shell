Based on the \href{https://github.com/gmounie/ensimag-shell}{\texttt{ensimag-\/shell}} skeleton.\hypertarget{index_autotoc_md1}{}\doxysection{\texorpdfstring{Build}{Build}}\label{index_autotoc_md1}

If the shell is waiting at its prompt at that moment, the prompt line is cleared and the prompt is redrawn below the message.\hypertarget{index_autotoc_md3}{}\doxysection{\texorpdfstring{Test}{Test}}\label{index_autotoc_md3}

It covers:


\begin{DoxyItemize}
\item line reading and command parsing (including the background {\ttfamily \&} flag and misplaced-\/{\ttfamily \&} errors)
\item foreground vs. background execution, and failed commands not duplicating buffered output
\item the {\ttfamily jobs} command and the job table, including a background pipeline being listed and reported as a single job
\item process computation time: the completion message, its timing, the {\ttfamily SIGCHLD} handler reaping finished jobs, and the prompt redraw
\item simple and multiple pipes ({\ttfamily cmd1 \texorpdfstring{$\vert$}{|} cmd2 \texorpdfstring{$\vert$}{|} ...}), input and output redirection, and background pipelines
\item regressions for pipelines that used to hang (output larger than the pipe buffer, readers that exit early such as {\ttfamily yes \texorpdfstring{$\vert$}{|} head -\/n 1})
\item wildcards ({\ttfamily \texorpdfstring{$\ast$}{*}}, {\ttfamily \+[]}, {\ttfamily \texorpdfstring{$\sim$}{\string~}}), environment variables ({\ttfamily \$VAR}), and quoted arguments containing {\ttfamily \textquotesingle{}} or {\ttfamily "{}}

\hypertarget{index_autotoc_md5}{}\doxysection{\texorpdfstring{Known limitations}{Known limitations}}\label{index_autotoc_md5}

\begin{DoxyItemize}
\item Background jobs write directly to the terminal, so their output can land after the prompt (e.\+g. {\ttfamily echo yes \&}), as in bash.
\item When a completion message redraws the prompt, any half-\/typed input is discarded, since it is no longer visible.
\item At most 10 background jobs at a time, and 16 processes per job.
\item {\ttfamily \$\{VAR\}} is not expanded. Because the parser removes quotes before expansion, {\ttfamily \textquotesingle{}\$HOME\textquotesingle{}} is still expanded, while a double-\/quoted argument containing spaces (e.\+g. {\ttfamily "{}\$HOME x"{}}) is not.
\item Ctrl-\/C is not handled: it stops the shell along with the foreground command.
\end{DoxyItemize}\hypertarget{index_autotoc_md6}{}\doxysection{\texorpdfstring{Authors}{Authors}}\label{index_autotoc_md6}
