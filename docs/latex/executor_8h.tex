int execute (\begin{DoxyParamCaption}\item[{struct \doxymbox{\hyperlink{structcmdline}{cmdline}} \texorpdfstring{$\ast$}{*}}]{l}{}\end{DoxyParamCaption})}



Executes a command pipeline. 

Every command is started before any is waited on: waiting for each in turn deadlocks as soon as a command writes more than the pipe buffer holds, since its reader has not been started yet. So only the last command is waited on as it is launched; the earlier ones are waited on once it has finished. All descriptors the shell opens are close-\/on-\/exec, so a child keeps only its own stdin/\+stdout; in particular a writer keeps no copy of its pipe\textquotesingle{}s read end, so it gets SIGPIPE when the reader exits early (e.\+g. {\ttfamily yes \texorpdfstring{$\vert$}{|} head -\/n 1}).

A background command line is recorded as a single job, whatever the number of commands in its pipeline.
